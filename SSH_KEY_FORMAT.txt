✅ ED25519 FORMAT (RECOMMENDED):

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIJl3dIeudNqd0DPMRD6OIh65A9pu0hQZzr1nJdMLFmGC your_email@example.com

Parts:
  ├─ Algorithm: ssh-ed25519
  ├─ Key Data:  AAAAC3NzaC1lZDI1... (51 characters)
  └─ Comment:   your_email@example.com

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ RSA FORMAT (TRADITIONAL):

ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABgQC8xOvfTz9uJvhSH8p7qRG5z... your_email@example.com

Parts:
  ├─ Algorithm: ssh-rsa
  ├─ Key Data:  AAAAB3NzaC1yc2EA... (much longer, 500+ characters)
  └─ Comment:   your_email@example.com

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 QUICK COMMANDS:

1. Generate Key (ED25519):
   $ ssh-keygen -t ed25519 -C "your_email@example.com"

2. Generate Key (RSA):
   $ ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

3. View Public Key:
   $ cat ~/.ssh/id_ed25519.pub
   or
   $ cat ~/.ssh/id_rsa.pub

4. Copy to Clipboard (Mac):
   $ cat ~/.ssh/id_ed25519.pub | pbcopy

5. Test GitHub Connection:
   $ ssh -T git@github.com

⚠️  IMPORTANT NOTES:

1. PUBLIC key (.pub file) - Share this with GitHub
   ✅ Safe to share
   ✅ This is what you paste in GitHub

2. PRIVATE key (no extension) - KEEP SECRET!
   ❌ Never share
   ❌ Never paste in GitHub
   ❌ Never commit to git

3. Files Location:
   Public:  ~/.ssh/id_ed25519.pub  (share this)
   Private: ~/.ssh/id_ed25519      (keep secret)

4. One Line: The key should be all on ONE line
   ✅ Correct: ssh-ed25519 AAAA...xyz email@example.com
   ❌ Wrong:   ssh-ed25519 AAAA...
               xyz email@example.com

📍 GITHUB SSH SETTINGS:

Direct link: https://github.com/settings/keys

Steps:
1. Click "New SSH key"
2. Title: Any name (e.g., "MacBook Air")
3. Key Type: Authentication Key
4. Key: Paste your PUBLIC key here
5. Click "Add SSH key"
